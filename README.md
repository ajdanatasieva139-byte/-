# Описание проекта
Данный проект представляет собой простую программу на языке Python для проверки надёжности пароля. Программа анализирует введённый пользователем пароль и определяет, соответствует ли он базовым требованиям безопасности.
# Как работает программа
Пользователь вводит пароль с клавиатуры.
Программа передаёт этот пароль в функцию check_password.
Функция выполняет несколько проверок:
длина пароля
наличие цифр
наличие специальных символов
Если пароль не соответствует какому-либо условию, программа возвращает сообщение с ошибкой.
Если все условия выполнены — выводится сообщение, что пароль надёжный.
# Код программы
import re

def check_password(password):
    # Проверка длины
    if len(password) < 8:
        return "Пароль слишком короткий (минимум 8 символов)"

    # Проверка на наличие цифры
    if not any(char.isdigit() for char in password):
        return "Пароль должен содержать хотя бы одну цифру"

    # Проверка на наличие специального символа
    if not re.search(r"[!@#$%^&*(),.?\":{}|<>]", password):
        return "Пароль должен содержать хотя бы один специальный символ"

    return "Пароль надёжный"


# Пример использования
user_password = input("Введите пароль: ")
result = check_password(user_password)
print(result)

# Используемые функции и элементы
1. len()
Используется для определения длины строки (пароля).
2. any()
Проверяет, есть ли хотя бы один символ, удовлетворяющий условию (например, цифра).
3. str.isdigit()
Метод строки, который проверяет, является ли символ цифрой.
4. re.search()
Функция из модуля re, используется для поиска специальных символов по шаблону (регулярному выражению).
5. input()
Позволяет пользователю ввести данные с клавиатуры.
6. print()
Выводит результат работы программы на экран.
